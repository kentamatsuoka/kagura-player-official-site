YOMUVIAの基本操作を、実際の作業順にまとめました。

PRO ACTIVATION

購入後、3ステップでProにする

購入完了ページは閉じずに、表示された認証番号をコピーしてください。認証番号は購入者本人だけで使用します。

01

設定メニューを開く

YOMUVIA上部の「設定」から「設定を開く...」を選びます。

02

PROタブへ貼り付ける

「PRO」タブの購入完了コード欄へ認証番号を貼り、「PROを有効にする」を押します。

03

契約管理・解約も同じ画面

認証後は「契約を管理・解約」が表示されます。Stripeの画面で解約を確定すると、次回以降は請求されません。

解約だけを確認したい方はこちら

動画を開く

  1. ファイルまたはフォルダをウィンドウへドラッグします。
  2. 複数動画はプレイリストへ追加されます。
  3. よく見る動画は星ボタンでお気に入りへ保存できます。

AI字幕を出す

  1. 字幕ボタンを押します。未生成動画はこの操作で初めて音声認識を開始します。
  2. 現在位置付近のドラフト字幕が先に表示されます。
  3. 高精度な全体字幕はバックグラウンドで生成され、自動的に差し替わります。
  4. 一時停止中に表示字幕をダブルクリックすると編集できます。

音声認識はローカルです。クラウド補正・翻訳はAPI設定時だけ使用します。

切り抜く

  1. Aボタンで開始、Bボタンで終了を決めます。
  2. ハサミボタンから保存先とファイル名を確認します。
  3. 字幕がありPro権限が有効な場合は「字幕を付ける」を選べます。
  4. 保存中も再生を続けられます。完成動画は切り抜きタブへ追加されます。

結合する

  1. 切り抜きタブで動画を右クリックし「結合画面に追加」を選びます。
  2. ドラッグまたは上下ボタンで順番を変更します。
  3. 左のプレビューで内容を確認します。
  4. 「この順番で結合する」を押します。

同一系統の形式・コーデック向けの高速結合です。異なる動画の自動変換は現在の対象外です。
